# LLMOps · Un agente con LangChain, desplegado con CRISP-ML(Q)

En el laboratorio anterior operaste una aplicación con LLM: una llamada al modelo y una respuesta con contrato. Aquí el modelo decide los pasos. Construyes un agente de retención con LangChain que consulta al cliente, pide su probabilidad de churn y registra una oferta, y lo llevas a producción con las seis fases de CRISP-ML(Q): en cada una, un requisito, un riesgo y el control que lo detecta.

| | Laboratorio 1 | Este laboratorio |
|---|---|---|
| Qué es | Aplicación con LLM | Agente |
| Quién decide el flujo | Tu código | El modelo, dentro de los límites que pone el entorno |
| Qué se evalúa | La respuesta | La tarea completa: el resultado y el camino |
| Qué puede salir mal | Una salida fuera de contrato | Una acción equivocada sobre un sistema real |

## Qué vas a construir

```
Ticket + id del cliente
        │
        ▼
Agente (LangChain) ── prompt versionado ── límite de pasos (lo impone el entorno)
        │
        ├─► consultar_cliente      datos del cliente
        ├─► predecir_churn         probabilidad de churn (el modelo del lab 14)
        └─► registrar_oferta       la acción; descuento_30 queda pendiente de aprobación
        │
        └─► una traza por tarea ─► monitor.py ─► REVISAR (exit 42)

GitHub Actions: Preparación (tests sin red) ─► Evaluación (eval de trayectoria + gate; el juez viene de main) ─► Despliegue (imagen Docker + smoke test)
```

## Mapa del laboratorio en CRISP-ML(Q)

| Fase | Qué haces | Riesgo | Control (quality gate) | Dónde vive |
|---|---|---|---|---|
| 1. Negocio y datos | Definir la tarea, la política de retención y el golden set | El agente optimiza algo que el negocio no pidió | Umbrales y política escritos antes del prompt | `gate/thresholds.json`, `data/golden.jsonl` |
| 2. Preparación | Herramientas con contrato | Una herramienta acepta cualquier cosa | Validación de entrada y aprobación para lo caro | `src/tools.py` |
| 3. Modelado | Agente y prompt versionado | Un bucle sin fin o sin control | Límite de pasos impuesto por el entorno | `src/agent.py`, `prompts/agente/` |
| 4. Evaluación | Eval de trayectoria y gate | Llega a la oferta correcta por el camino equivocado | Scorer de trayectoria, baseline | `src/evaluate.py`, `src/gate.py` |
| 5. Despliegue | API, imagen y pipeline | Quien propone el cambio cambia el examen | El juez se toma de `main`; imagen sin root | `src/api.py`, `Dockerfile`, `agent.yml` |
| 6. Monitoreo | Trazas y alertas | El agente empieza a regalar descuentos y nadie lo ve | PSI de las ofertas, pasos, errores de herramienta | `src/replay.py`, `src/monitor.py` |

## Requisitos

- Python 3.11 o superior (LangChain 1.5 no instala en versiones anteriores), git y Docker.
- Cuenta de GitHub.
- API key de [Groq](https://console.groq.com). En este laboratorio es obligatoria: un agente necesita un modelo real que sepa usar herramientas. Los tests sí corren sin red.

> **Límites del plan gratuito de Groq** (medidos en noviembre de 2026 con `qwen/qwen3.8-27b`): 8 000 tokens por minuto, 200 000 tokens por día y 1 000 requests por día. Cada tarea del agente usa unos 2 900 tokens en 4 requests. Por eso el eval y el replay esperan 22 segundos entre tareas (`PAUSA_ENTRE_TAREAS`): un eval de 10 tareas tarda unos 4 minutos. El límite diario también cuenta: cada eval gasta unos 29 000 tokens y los dos replays de la fase 6 unos 46 000, y el eval del pipeline usa la misma key. No repitas evals sin necesidad. Tus límites están en la consola de Groq → **Settings** → **Limits**; si son distintos, ajusta la pausa.

## Fase 2 · Preparación: las herramientas

Crea `src/tools.py`:

```python
"""Herramientas del agente. Cada una tiene un contrato: valida su entrada y
devuelve JSON. Los controles viven aquí, en el entorno, no en el prompt."""
import csv
import json
import os
import time
from pathlib import Path

from langchain.tools import tool

ROOT = Path(__file__).resolve().parents[1]
OFERTAS = ("ninguna", "descuento_10", "descuento_30", "llamada_ejecutivo")
REQUIERE_APROBACION = ("descuento_30",)  # las ofertas caras no se ejecutan solas


def clientes() -> dict:
    with (ROOT / "data" / "clientes.csv").open(encoding="utf-8") as handle:
        return {row["cliente_id"]: row for row in csv.DictReader(handle)}


def probabilidad_churn(cliente: dict) -> float:
    """Sustituto del modelo del lab 14: en producción sería la API de churn."""
    score = (0.15 + 0.12 * int(cliente["tickets_90d"])
             + (0.25 if cliente["contrato"] == "mensual" else 0.0)
             - 0.004 * int(cliente["antiguedad_meses"])
             + 0.002 * (float(cliente["cuota_mensual"]) - 50))
    return round(min(max(score, 0.02), 0.98), 2)


def politica(probabilidad: float, antiguedad_meses: int) -> str:
    """La política de retención del negocio. El juez la usa como referencia."""
    if probabilidad >= 0.6:
        return "descuento_30" if antiguedad_meses >= 12 else "llamada_ejecutivo"
    return "descuento_10" if probabilidad >= 0.3 else "ninguna"


@tool
def consultar_cliente(cliente_id: str) -> str:
    """Devuelve plan, contrato, cuota mensual, antigüedad en meses y tickets de los últimos 90 días."""
    cliente = clientes().get(cliente_id)
    if not cliente:
        return json.dumps({"error": f"cliente {cliente_id} no existe"})
    return json.dumps(cliente, ensure_ascii=False)


@tool
def predecir_churn(cliente_id: str) -> str:
    """Devuelve la probabilidad (0 a 1) de que el cliente se vaya, según el modelo de churn."""
    cliente = clientes().get(cliente_id)
    if not cliente:
        return json.dumps({"error": f"cliente {cliente_id} no existe"})
    return json.dumps({"cliente_id": cliente_id, "probabilidad_churn": probabilidad_churn(cliente)})


@tool
def registrar_oferta(cliente_id: str, oferta: str) -> str:
    """Registra la oferta de retención decidida para el cliente. Valores: ninguna, descuento_10, descuento_30, llamada_ejecutivo."""
    if cliente_id not in clientes():
        return json.dumps({"error": f"cliente {cliente_id} no existe"})
    if oferta not in OFERTAS:
        return json.dumps({"error": f"oferta inválida; usa una de {list(OFERTAS)}"})
    estado = "pendiente_aprobacion" if oferta in REQUIERE_APROBACION else "registrada"
    registro = {"ts": time.strftime("%Y-%m-%dT%H:%M:%S"), "cliente_id": cliente_id, "oferta": oferta, "estado": estado}
    path = Path(os.getenv("OFERTAS_FILE", ROOT / "logs" / "ofertas.jsonl"))
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("a", encoding="utf-8") as handle:
        handle.write(json.dumps(registro, ensure_ascii=False) + "\n")
    return json.dumps(registro, ensure_ascii=False)


TOOLS = [consultar_cliente, predecir_churn, registrar_oferta]
```

Lo que importa de este archivo:

- Cada herramienta valida su entrada y devuelve un error legible. El agente puede equivocarse al llamarla; la herramienta no debe ejecutar algo inválido.
- `registrar_oferta` es la única que actúa. Las ofertas caras (`descuento_30`) no se ejecutan: quedan en `pendiente_aprobacion` para que una persona decida. Ese control está en el código de la herramienta, donde el modelo no puede cambiarlo.
- `probabilidad_churn` es un sustituto del modelo del laboratorio 14. En producción esa herramienta llamaría a la API de churn desplegada.
- `politica` no la usa el agente: es la referencia con la que el juez comprueba el golden set.

Crea `src/agent.py`:

```python
"""El agente de retención: lee un ticket, consulta al cliente, pide la probabilidad
de churn y registra una oferta. El modelo decide los pasos; el entorno pone los límites."""
import json
import os
import sys
import time
from pathlib import Path

from langchain.agents import create_agent
from langchain_openai import ChatOpenAI
from langgraph.errors import GraphRecursionError

from src.tools import TOOLS

ROOT = Path(__file__).resolve().parents[1]


def load_config() -> dict:
    return json.loads((ROOT / "config.json").read_text(encoding="utf-8"))


def load_prompt(version: str) -> str:
    return (ROOT / "prompts" / load_config()["prompt"] / f"{version}.md").read_text(encoding="utf-8")


def chat_model():
    return ChatOpenAI(
        model=os.getenv("LLM_MODEL", "qwen/qwen3.8-27b"),
        base_url=os.getenv("LLM_BASE_URL", "https://api.groq.com/openai/v1"),
        api_key=os.environ["LLM_API_KEY"],
        temperature=0,
        max_tokens=load_config()["max_tokens"],
        max_retries=6,
        timeout=60,
    )


def pausa() -> None:
    """Espera entre tareas para no pasar el límite de tokens por minuto del plan gratuito."""
    time.sleep(float(os.getenv("PAUSA_ENTRE_TAREAS", "22")))


def progreso(hechas: int, total: int) -> None:
    """Avance en la terminal: entre tarea y tarea hay una pausa de varios segundos."""
    if sys.stderr.isatty():
        print(f"\r  tarea {hechas}/{total}", end="\n" if hechas == total else "", file=sys.stderr, flush=True)


def atender(cliente_id: str, ticket: str, version: str | None = None, model=None,
            trace_file: Path | None = None) -> dict:
    config = load_config()
    version = version or config["prompt_version"]
    agent = create_agent(model or chat_model(), TOOLS, system_prompt=load_prompt(version))
    entrada = {"messages": [{"role": "user", "content": f"Cliente: {cliente_id}\nTicket: {ticket}"}]}
    start = time.perf_counter()
    estado, messages = "completada", []
    try:
        # El límite de pasos lo impone el entorno: el agente no puede cambiarlo
        for state in agent.stream(entrada, config={"recursion_limit": config["max_pasos"]}, stream_mode="values"):
            messages = state["messages"]
    except GraphRecursionError:
        estado = "limite_de_pasos"

    trayectoria, tokens, respuesta, errores = [], 0, "", 0
    for message in messages:
        if message.type == "ai":
            tokens += (message.usage_metadata or {}).get("total_tokens", 0)
            trayectoria += [{"herramienta": call["name"], "args": call["args"]} for call in message.tool_calls]
            respuesta = message.content or respuesta
        elif message.type == "tool" and '"error"' in str(message.content):
            errores += 1
    registros = [paso["args"].get("oferta") for paso in trayectoria if paso["herramienta"] == "registrar_oferta"]
    trace = {
        "ts": time.strftime("%Y-%m-%dT%H:%M:%S"),
        "prompt": f"{config['prompt']}/{version}",
        "cliente_id": cliente_id,
        "ticket": ticket,
        "estado": estado,
        "oferta": registros[-1] if registros else None,
        "trayectoria": trayectoria,
        "pasos": len(trayectoria),
        "errores_herramienta": errores,
        "tokens": tokens,
        "latency_s": round(time.perf_counter() - start, 2),
        "respuesta": respuesta,
    }
    if trace_file:
        trace_file.parent.mkdir(parents=True, exist_ok=True)
        with trace_file.open("a", encoding="utf-8") as handle:
            handle.write(json.dumps(trace, ensure_ascii=False) + "\n")
    return trace


if __name__ == "__main__":
    out = atender(sys.argv[1], " ".join(sys.argv[2:]))
    for paso in out["trayectoria"]:
        print(f"  -> {paso['herramienta']}({paso['args']})")
    print(json.dumps({k: out[k] for k in ("estado", "oferta", "pasos", "tokens", "latency_s", "respuesta")},
                     ensure_ascii=False, indent=2))
```

- `create_agent` arma el bucle: el modelo pide una herramienta, LangChain la ejecuta, el resultado vuelve al modelo y así hasta que responde sin pedir más.
- `recursion_limit` corta el bucle. Si el agente no termina en `max_pasos`, la tarea queda en `limite_de_pasos`. El límite está en la configuración del entorno, no en el prompt.
- La traza guarda la trayectoria: qué herramientas llamó, con qué argumentos y en qué orden.
- `pausa` y `progreso` son para el eval y el replay: esperan entre tareas por el límite de tokens por minuto y muestran el avance (`tarea 3/10`) para que no parezcan colgados.

## Fase 4 · Evaluación

Crea `src/evaluate.py`:

```python
"""Eval del agente: corre tareas completas y califica el resultado y el camino.

Un agente puede llegar a la oferta correcta por el camino equivocado (sin consultar
al cliente) o gastar pasos de más, así que se evalúa la trayectoria, no solo el final.
"""
import argparse
import json
from pathlib import Path

from src import agent

ROOT = Path(__file__).resolve().parents[1]


def trayectoria_valida(trayectoria: list[dict]) -> bool:
    """Consultó al cliente y pidió el churn antes de registrar, y registró una sola vez."""
    nombres = [paso["herramienta"] for paso in trayectoria]
    if nombres.count("registrar_oferta") != 1:
        return False
    antes = nombres[:nombres.index("registrar_oferta")]
    return "consultar_cliente" in antes and "predecir_churn" in antes


def run(version: str, model=None) -> dict:
    cases = [json.loads(line) for line in
             (ROOT / "data" / "golden.jsonl").read_text(encoding="utf-8").splitlines() if line.strip()]
    rows = []
    for index, case in enumerate(cases):
        if model is None and index:
            agent.pausa()
        out = agent.atender(case["cliente_id"], case["ticket"], version=version, model=model)
        agent.progreso(index + 1, len(cases))
        rows.append({
            "id": case["id"], "tipo": case["tipo"], "esperado": case["oferta"], "obtenido": out["oferta"],
            "ok": out["estado"] == "completada" and out["oferta"] == case["oferta"],
            "trayectoria_ok": trayectoria_valida(out["trayectoria"]),
            "limite": out["estado"] == "limite_de_pasos",
            "pasos": out["pasos"], "tokens": out["tokens"], "latency_s": out["latency_s"],
            "camino": " > ".join(paso["herramienta"] for paso in out["trayectoria"]) or "sin herramientas",
        })
    normal = [row for row in rows if row["tipo"] == "normal"]
    attacks = [row for row in rows if row["tipo"] == "inyeccion"]
    rate = lambda items, key: round(sum(item[key] for item in items) / len(items), 3)
    latencies = sorted(row["latency_s"] for row in rows)
    metrics = {
        "tarea_completada": rate(normal, "ok"),
        "trayectoria_valida": rate(rows, "trayectoria_ok"),
        "resistencia_inyeccion": rate(attacks, "ok"),
        "pasos_promedio": round(sum(row["pasos"] for row in rows) / len(rows), 2),
        "limite_de_pasos": rate(rows, "limite"),
        "tokens_promedio": round(sum(row["tokens"] for row in rows) / len(rows), 1),
        "latencia_p95_s": latencies[min(len(latencies) - 1, int(round(0.95 * (len(latencies) - 1))))],
    }
    return {"prompt_version": version, "casos": len(rows), "metrics": metrics, "rows": rows}


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--prompt-version", default=agent.load_config()["prompt_version"])
    args = parser.parse_args()
    report = run(args.prompt_version)
    reports = ROOT / "reports"
    reports.mkdir(exist_ok=True)
    (reports / "eval.json").write_text(json.dumps(report, ensure_ascii=False, indent=2), encoding="utf-8")

    failed = [row for row in report["rows"] if not (row["ok"] and row["trayectoria_ok"])]
    lines = [f"## Eval del agente · prompt {report['prompt_version']}", "", "| Métrica | Valor |", "|---|---|"]
    lines += [f"| {name} | {value} |" for name, value in report["metrics"].items()]
    lines += ["", f"### Tareas falladas ({len(failed)} de {report['casos']})", "",
              "| id | tipo | esperado | obtenido | camino |", "|---|---|---|---|---|"]
    lines += [f"| {row['id']} | {row['tipo']} | {row['esperado']} | {row['obtenido']} | {row['camino']} |"
              for row in failed]
    (reports / "eval.md").write_text("\n".join(lines) + "\n", encoding="utf-8")

    print(f"Prompt {report['prompt_version']} · {report['casos']} tareas")
    for name, value in report["metrics"].items():
        print(f"  {name:<24}{value}")
    print(f"Tareas falladas: {len(failed)} (detalle en reports/eval.md)")


if __name__ == "__main__":
    main()
```

```python
"""El juez: decide si una versión del agente puede llegar a producción.

Lee reports/eval.json y lo compara con los umbrales y con el baseline. Quien propone
el cambio (una persona o un agente) no debe poder editar este archivo ni gate/.
"""
import json
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]


def main() -> int:
    metrics = json.loads((ROOT / "reports" / "eval.json").read_text(encoding="utf-8"))["metrics"]
    rules = json.loads((ROOT / "gate" / "thresholds.json").read_text(encoding="utf-8"))
    baseline = json.loads((ROOT / "gate" / "baseline.json").read_text(encoding="utf-8"))

    if "--write-baseline" in sys.argv:
        (ROOT / "gate" / "baseline.json").write_text(json.dumps(metrics, indent=2) + "\n", encoding="utf-8")
        print("gate/baseline.json actualizado con las métricas de reports/eval.json")
        return 0

    failures = []
    print(f"{'métrica':<24}{'valor':>8}  {'regla':<22}resultado")
    for name, limit in rules["minimo"].items():
        ok = metrics[name] >= limit
        print(f"{name:<24}{metrics[name]:>8}  {'>= ' + str(limit):<22}{'OK' if ok else 'FALLA'}")
        failures += [] if ok else [name]
    for name, limit in rules["maximo"].items():
        ok = metrics[name] <= limit
        print(f"{name:<24}{metrics[name]:>8}  {'<= ' + str(limit):<22}{'OK' if ok else 'FALLA'}")
        failures += [] if ok else [name]
    for name in rules["no_empeorar"]:
        floor = max(0, round(baseline[name] - rules["tolerancia"], 3))
        ok = metrics[name] >= floor
        print(f"{name:<24}{metrics[name]:>8}  {'>= baseline ' + str(floor):<22}{'OK' if ok else 'FALLA'}")
        failures += [] if ok else [f"{name} vs baseline"]

    if failures:
        print(f"\nGATE: RECHAZADO · {', '.join(failures)}")
        return 1
    print("\nGATE: APROBADO")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
from src.tools import clientes

    return {key: out[key] for key in ("estado", "oferta", "pasos", "tokens", "latency_s", "respuesta")}
```

```yaml
name: Agent Pipeline

on:
  pull_request:
  push:

          LLM_API_KEY: ""

  eval:
    name: Evaluación · eval y gate

      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - run: pip install -r requirements.txt

      - name: Comprobar el secret

            exit 1
          fi

      # El juez no viene del PR: se toma de main
      - name: Tomar el juez desde main
        if: github.event_name == 'pull_request'
        run: |
          for item in gate data/golden.jsonl src/evaluate.py src/gate.py; do
            if git cat-file -e "origin/${{ github.base_ref }}:$item" 2>/dev/null; then
              git checkout "origin/${{ github.base_ref }}" -- "$item"

              echo "::warning::$item todavía no existe en ${{ github.base_ref }}; se usa el del PR"
            fi

          git status --short

      - name: Evaluar

      - name: Reporte en el resumen del job

      - uses: actions/upload-artifact@v4
        if: always()
        continue-on-error: true  # sin cuota de artifacts el gate corre igual; el reporte ya está en el resumen
```

```python
"""Monitoreo del agente: compara las trazas de una semana con la de referencia.
Vigila qué ofertas entrega (PSI), cuántos pasos da, si choca con el límite, los
errores de herramienta y los tokens. Sale con 42 cuando hay que revisar."""
import json
import math
import sys
from collections import Counter
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
OFERTAS = ["ninguna", "descuento_10", "descuento_30", "llamada_ejecutivo", "sin_oferta"]


def load(path: str) -> list[dict]:
    return [json.loads(line) for line in Path(path).read_text(encoding="utf-8").splitlines() if line.strip()]


def summary(traces: list[dict]) -> dict:
    counts = Counter(trace["oferta"] or "sin_oferta" for trace in traces)
    pasos = sorted(trace["pasos"] for trace in traces)
    total = len(traces)
    return {
        "tareas": total,
        "mezcla": {name: round(counts[name] / total, 3) for name in OFERTAS},
        "limite_de_pasos": round(sum(trace["estado"] == "limite_de_pasos" for trace in traces) / total, 3),
        "errores_herramienta": round(sum(trace["errores_herramienta"] > 0 for trace in traces) / total, 3),
        "pasos_p95": pasos[min(total - 1, int(round(0.95 * (total - 1))))],
        "tokens_promedio": round(sum(trace["tokens"] for trace in traces) / total, 1),
    }


def psi(reference: dict, current: dict) -> float:
    total = 0.0
    for name in OFERTAS:
        ref, cur = max(reference[name], 0.01), max(current[name], 0.01)
        total += (cur - ref) * math.log(cur / ref)
    return round(total, 3)


def main() -> int:
    reference, current = summary(load(sys.argv[1])), summary(load(sys.argv[2]))
    limits = json.loads((ROOT / "gate" / "thresholds.json").read_text(encoding="utf-8"))["monitoreo"]
    values = {
        "psi_ofertas": psi(reference["mezcla"], current["mezcla"]),
        "limite_de_pasos": current["limite_de_pasos"],
        "errores_herramienta": current["errores_herramienta"],
        "pasos_p95": current["pasos_p95"],
        "tokens_vs_referencia": round(current["tokens_promedio"] / reference["tokens_promedio"], 2),
    }
    alerts = [name for name, value in values.items() if value > limits[name]]

    print(f"{'oferta':<20}{'referencia':>11}{'actual':>9}")
    for name in OFERTAS:
        print(f"{name:<20}{reference['mezcla'][name]:>11}{current['mezcla'][name]:>9}")
    print(f"\n{'señal':<24}{'valor':>8}  {'límite':<10}resultado")
    for name, value in values.items():
        print(f"{name:<24}{value:>8}  {'<= ' + str(limits[name]):<10}{'ALERTA' if name in alerts else 'OK'}")
    decision = "REVISAR" if alerts else "OK"
    (ROOT / "reports").mkdir(exist_ok=True)
    (ROOT / "reports" / "monitoring.json").write_text(json.dumps(
        {"decision": decision, "alertas": alerts, "senales": values, "referencia": reference, "actual": current},
        ensure_ascii=False, indent=2), encoding="utf-8")
    print(f"\nDECISIÓN: {decision}" + (f" · {', '.join(alerts)}" if alerts else ""))
    return 42 if alerts else 0


if __name__ == "__main__":
    sys.exit(main())
```

## Problemas frecuentes

| Síntoma | Causa | Solución |
|---|---|---|
| `No matching distribution found for langchain==1.5.0` | Python menor que 3.11 | Crea el entorno con conda (paso 0, opción A), que instala Python 3.11 |
| `ModuleNotFoundError: No module named 'src'` al correr los tests | Ejecutaste `pytest` a secas: no agrega la carpeta del proyecto a la ruta de imports | `python -m pytest -q`, desde la raíz del proyecto |
| `KeyError: 'LLM_API_KEY'` | La variable no está en esa terminal | `export LLM_API_KEY=...` |
| `src.evaluate` o `src.replay` parecen colgados | No están colgados: esperan `PAUSA_ENTRE_TAREAS` segundos entre tareas. El eval tarda unos 4 minutos y cada replay unos 3 | Espera a que el contador llegue al final (`tarea 10/10`) |
| El eval tarda mucho o `latencia_p95_s` sale alta | Pasaste los tokens por minuto y el cliente reintenta | Sube `PAUSA_ENTRE_TAREAS` (segundos) |
| `Error code: 429` después de varios evals | Agotaste los tokens o los requests del día | Espera al día siguiente o usa otro modelo con `LLM_MODEL`. Tus límites están en la consola de Groq → **Settings** → **Limits** |
| `model not found` | El modelo de la guía ya no existe en Groq | Elige otro que soporte herramientas y expórtalo en `LLM_MODEL` |
| El agente no llama herramientas | El modelo elegido no soporta tool calling | Cambia de modelo |
| No puedes hacer push (`Permission denied` o 403) | Clonaste el repositorio de la organización y no tu fork | `git remote set-url origin https://github.com/<tu-usuario>/llmops-agent-lab.git` |
| El job `Evaluación · eval y gate` falla en "Comprobar el secret" | Falta el secret | Paso 5.3 |
